---
title: "GET /api/scan"
description: "Measure one chain."
---

```bash
curl 'https://YOUR_DEPLOY.vercel.app/api/scan?chain=base&units=150'
```

## Query parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| `chain` | `xrpl` or `base` | **yes** | — |
| `units` | number | no | `150` |
| `key` | string | no | — (or `x-api-key` header) |

```json
      }

```

<Note>
**Always check `sampling.scanned` against `sampling.requested`.** Public RPCs throttle, and a
thin sample produces an inflated score.
</Note>

## Notable fields

| Field | Meaning |
|---|---|
| `authenticity.omittedSignals` | Signals that could not be measured on this chain |
| `values.distinct` | Distinct payment amounts — the strongest signal |
| `usd.perDay` | **Extrapolated** from the sampled window |
| `clamped` | Present when `units` exceeded your tier ceiling |
| `cache` | `hit` or `miss` |
